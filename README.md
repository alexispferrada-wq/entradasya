## 📌 Descripción

**EntradasYa** es una plataforma ágil para la venta de tickets para eventos, fiestas, presentaciones y espectáculos en vivo. Ofrece emisión de tickets con código QR verificable en segundos y asistencia conversacional inteligente.

---

## 🚀 Capacidades

- **Venta directa de tickets:** Pasarela optimizada para compra rápida desde el móvil.
- **Validación por QR:** Check-in rápido en puerta para evitar duplicaciones o falsificaciones.
- **Asistencia Inteligente:** Integrado con agentes conversacionales para resolver dudas de ubicación, horarios y políticas de acceso.
